朋友连不上？先看这里

    
    
      
  • 第一次开服 Windows 会弹「安全中心警报」：勾专用网络 → 允许访问。没弹或点错了，用管理员 PowerShell 执行下面这条（添加防火墙规则）：
    • 
    

    
netsh advfirewall firewall add rule name="Stronghold Protocol" dir=in action=allow protocol=TCP localport=3000 profile=private,domain

    

      
      网络若被识别为「公用网络」，Windows 会拦截入站：管理员 PowerShell 执行
        Set-NetConnectionProfile -InterfaceAlias "以太网" -NetworkCategory Private
    

    
    
      
  • 朋友要用 局域网 / Radmin 地址，不能用 localhost（那是他自己那台机器）。
    • 
      
  • 访客 Wi-Fi 常开「AP 隔离」，同一 Wi-Fi 也连不上：换路由器 / 用 Radmin VPN。
    • 
      
  • 主机 IP 变了地址就失效：在路由器里给小主机绑定固定 IP（DHCP 地址保留）。
    • 
      
  • 进阶：公网联机（cloudflared / Tailscale）、开机自启、排错见 docs\DEPLOY.md。
    • 
      
  • 服务器无存档：重启会结束进行中的对局。
